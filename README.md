
# 📊 MeausrePro - 계측 장비 상태 관리 시스템

> 공공건물이나 상업시설의 계측 데이터를 수집하고, 시각화 및 보고할 수 있는 **계측 장비 통합 관리 시스템**

---

## 📅 프로젝트 개요

- **기간**: 2024.10.02 ~ 2024.10.25
- **팀원 구성**: 5인 팀 프로젝트
- **개발 환경**:  
  - Frontend: React, Android Studio (Kotlin)  
  - Backend: Spring Boot, MySQL  
  - 배포: AWS EC2

---

## 🛠 주요 기능 요약

| 기능 영역 | 설명 |
|----------|------|
| 장비 관리 | 구간/계측기 등록, 삭제, 수정 기능 |
| 데이터 입력 | 계측기 실시간 측정값 등록 및 수정 |
| QR 기능 | 계측기 QR코드 생성 및 모바일 스캔 |
| 데이터 시각화 | 차트 및 SVG 아이콘을 활용한 상태 시각화 |
| PDF 출력 | 보고서 인쇄 레이아웃 및 PDF 출력용 UI 구성 |
| 관리자 구분 | 웹 관리자 / 앱 관리자 권한 분리 |
| 알림 및 오류 처리 | 입력 유효성 검사 및 사용자 피드백 |

---

## 🔗 시스템 구조

```plaintext
사용자
├─ 웹 관리자 (React)
│  ├─ 프로젝트/구간/계측기 관리
│  ├─ 실시간 데이터 확인 및 상태 시각화
│  └─ 리포트 확인 및 다운로드
├─ 앱 관리자 (Kotlin)
│  ├─ QR코드 스캔 후 장비 정보 입력
│  └─ 입력값을 서버로 전송
└─ 백엔드 서버 (Spring Boot)
    └─ REST API 기반 데이터 송수신 및 저장
```

---

## 💻 담당 역할 (Ethan / 박찬윤)

- **Spring Boot 기반 REST API 설계 및 구현**
  - DB 연동을 위한 JPA 및 SQL 작성
  - CRUD API 개발 (장비 등록, 수정, 삭제)
- **QR 연동 기능**
  - 계측기별 고유 QR 생성 및 모바일 연동 구현
- **데이터 시각화**
  - 계측기 상태에 따른 SVG 아이콘 상태 분기
  - 상태에 따라 차트 및 색상 실시간 변경 구현
- **보고서 출력 화면 및 print.css 적용**
